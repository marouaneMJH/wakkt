Build from source

Requirements: JDK 17 or newer (the build picks JDK 17 automatically if it's installed) and the Android SDK.

git clone https://github.com/marouaneMJH/wakkt.git
cd wakkt
./gradlew installDebug      # build and install on a connected phone
./gradlew testDebugUnitTest # run the unit tests

Release builds (./gradlew bundleRelease) need your own signing key in a keystore.properties file, which is never committed.

How it works

  • Kotlin + Jetpack Compose + Material 3, single activity, MVVM with Coroutines/Flow, Hilt, Room and DataStore.
  • A foreground service reads the current foreground app with UsageStatsManager and draws the note with WindowManager (TYPE_APPLICATION_OVERLAY).
  • Sounds are synthesized in code (no audio files); visuals are generated on a Compose canvas from a random seed, with a unit-tested cap on alternation speed for photosensitivity safety.
  • No network code and no internet permission.

Contributing

  • Bugs and ideas: open an issue. Include your phone model and Android version for bugs.
  • Code: fork, create a branch, keep changes focused, run ./gradlew lintDebug testDebugUnitTest, and open a pull request.
  • Principles: keep it private (no network, no trackers), keep setup minimal, keep it safe (no strobing).
  • Translations are welcome: all texts live in app/src/main/res/values/strings.xml.

Security

Found a security or privacy problem? Please open an issue without exploit details and ask for a private channel, or use GitHub's private vulnerability reporting on the repository.
